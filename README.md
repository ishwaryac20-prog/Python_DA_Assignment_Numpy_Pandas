# Python DA Assignment – NumPy & Pandas 🐍

## 📌 Project Overview

This project is part of the **Data Analytics (DA) – Numpy & Pandas** assignment.  
It focuses on performing data analysis and data manipulation using **NumPy and Pandas**.

## 🎯 Objectives

- 🟣 Create and work with NumPy arrays.
- 🟣 Perform numerical calculations and temperature conversion.
- 🟣 Apply indexing and slicing techniques.
- 🟣 Create and manipulate Pandas Series.
- 🟣 Explore and analyze Pandas DataFrames.
- 🟣 Perform filtering, grouping, and aggregation.
- 🟣 Update, add, and remove data from DataFrames.

## 🛠️ Tools & Technologies

- Python 🐍
- NumPy
- Pandas
- Google Colab
- Jupyter Notebook

## 📂 Assignment Tasks

### 🔢 NumPy Operations

- Created a 1D NumPy array for Week 1 temperature data.
- Inspected array shape, data type, and number of elements.
- Converted Celsius temperatures to Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Performed array indexing and slicing.
- Created a 2D NumPy array containing temperature data for two weeks.
- Extracted weekly and weekend temperature values.

### 🐼 Pandas Series

- Created a Pandas Series named `marks` with custom rank indexes.
- Used integer indexing, `loc`, and `iloc`.
- Applied Boolean filtering to identify marks greater than 90.
- Modified the mark of the first-rank student.
- Removed the last-rank entry.
- Calculated CGPA by dividing marks by 10.

### 📊 Pandas DataFrame

- Created a `transactions` DataFrame containing transaction, category, region, and amount details.
- Explored the DataFrame using `head()`, `tail()`, `shape`, column names, and data types.
- Selected specific columns and subsets.
- Filtered transactions based on region and amount.
- Used `value_counts()` to analyze product categories.
- Used `unique()` to identify available regions.
- Used `groupby()` and `mean()` to calculate average transaction amounts by region.
- Updated the amount for TransactionID 102.
- Added a `Discount` column.
- Removed TransactionID 109.
- Deleted the `Discount` column.

- DataFrame Creation & Exploration

- Grouping & Aggregation
- Data Updating & Deletion
